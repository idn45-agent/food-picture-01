# Food Picture 01 — Steaming Tonkotsu Ramen

A bowl of tonkotsu ramen rendered entirely in code: a speckled blue-grey ceramic bowl on a dark wooden table, creamy broth with glossy oil droplets and chili-oil sheen, a mound of wavy noodles, a lifted noodle pull held by wooden chopsticks, fanned chashu slices with fat marbling, a halved ajitama egg with a jammy amber yolk, a nori sheet, scallions, sesame and gentle rising steam, all in a warm izakaya mood with soft bokeh lights. The program (`main.py`, Python standard library only) paints into an 800x800 float framebuffer using gradient ellipses, scanline polygons, soft discs and stamped wavy strokes, lit by a warm radial glow with a gentle vignette, then writes `entry.png` with a hand-written PNG encoder (zlib + struct). It is fully deterministic: running it twice produces a byte-identical image.
