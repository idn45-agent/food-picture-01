# Food Picture 01 — Sushi Platter

A top-down sushi platter rendered entirely in code: glossy salmon and tuna nigiri, a tamago nigiri with a nori band, a row of maki rolls, wasabi, pickled ginger, a shiso leaf and a small soy-sauce dish, all arranged on a dark slate platter over a charcoal background. The program (`main.py`, Python standard library only) paints into an 800x800 framebuffer using shaded ellipses and rotated rounded rectangles — radial gradients for plumpness, diagonal fat stripes on the salmon, per-piece specular gloss highlights so the fish looks fresh and moist, soft drop shadows, and a deterministic hash-based grain for texture — then writes `entry.png` with a hand-written PNG encoder (zlib + struct). It is fully deterministic: running it twice produces a byte-identical image.
